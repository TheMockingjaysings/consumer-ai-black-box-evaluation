# Historical Scope Note: Agentic AI

> **Historical document notice — September 28, 2026:** This file reflects an earlier stage of the MOTHER project. The active project framing has moved away from a general authorization-boundary benchmark. See [`external-black-box-scope.md`](external-black-box-scope.md) and the repository README for the current research question.

## Historical context

This note is retained because it shows how the project originally separated ordinary conversational behavior from more agentic settings involving tools, actions, delegated authority, and execution boundaries.

The current project no longer treats that distinction as its primary research contribution. Related work has shown that authorization, delegation, least privilege, tool boundaries, abstention, and proceed/hold decisions are already active and well-developed research areas.

For current work, agentic systems may still be relevant as background literature, but the active methodological question is broader and more external:

> **What can an independent evaluator, using only public consumer AI interfaces, reliably observe, reproduce, and document when important deployment variables may be hidden or changing?**

This file should therefore be read as project history rather than as a current scope specification.
